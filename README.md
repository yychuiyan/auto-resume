# 招聘平台批量投递助手

Chrome 扩展，分两个独立版本：

| 版本 | 目录 | 说明 |
| --- | --- | --- |
| **1.0** | `extension-v1.0/` | 在搜索页抓取职位后批量投递，支持 BOSS、智联 |
| **2.0** | `extension-v2.0/` | 上传 Word 简历，AI 解析匹配规则后自动搜岗并批量投递，支持 BOSS、智联、前程无忧 |

两个扩展可同时安装，互不影响。

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选 `extension-v1.0/` 或 `extension-v2.0/`
5. 修改代码后需在该页重新加载对应扩展

也可从 [Releases](https://github.com/yychuiyan/auto-resume/releases) 下载 `extension-v1.0` / `extension-v2.0` 压缩包，解压后再按上面步骤加载。

## 1.0 搜索页抓取投递

点扩展图标打开弹窗。在对应平台搜索页搜好职位后，切到对应 Tab 抓取再投递。

### BOSS 直聘

| 步骤      | 操作                                |
| --------- | ----------------------------------- |
| 1. 搜职位 | 在 BOSS 搜索页输入关键词搜索        |
| 2. 抓取   | 🔵 BOSS Tab → **从搜索页抓取职位**  |
| 3. 投递   | 设置数量、间隔 → **开始批量打招呼** |

- 使用平台默认招呼语
- 自动调用搜索 API 获取 securityId，跳过详情页
- 触发风控自动停止并弹出 BOSS 页面

### 智联招聘

| 步骤      | 操作                               |
| --------- | ---------------------------------- |
| 1. 搜职位 | 在智联搜索页输入关键词搜索         |
| 2. 抓取   | 🔴 智联 Tab → **从搜索页抓取职位** |
| 3. 投递   | 设置数量、间隔 → **开始批量投递**  |

- 自动识别附件简历并投递
- 使用平台默认招呼语
- 支持后台运行（关闭弹窗后继续）

### 1.0 其它

- 每个 Tab 下方显示今日成功投递数，每天 0 点归零
- 关闭弹窗后日志保留；垃圾箱按钮清除日志
- 投递中工具栏显示红色取消按钮
- Chrome 需保持打开；各平台需已登录且有默认简历
- 投递间隔建议 3～5 秒，过快可能触发风控

## 2.0 AI 简历匹配投递

点工具栏图标打开侧边栏（不是弹窗）。先上传简历并解析，再按平台匹配、投递。

### 准备

1. 在侧边栏填写 DeepSeek API Key 并保存（默认 `deepseek-v4-flash`）
2. 上传 `.docx` 简历 → **解析简历**
3. 核对职位、城市、技能、工作词，以及最低月薪、公司规模
4. 点 **保存匹配规则**（解析不会覆盖已选薪资/规模）

画像只存在本机 Chrome，不会上传到本仓库。删除简历后需重新上传才能匹配。

### 匹配与投递

| 平台        | 怎么找岗位                   | 怎么投                           |
| ----------- | ---------------------------- | -------------------------------- |
| BOSS / 智联 | 按画像职位 + 城市自动搜 2 页 | 后台批量打招呼 / 投递            |
| 前程无忧    | 读取**当前搜索页**列表       | 后台复制搜索页点申请，本页不跳走 |

流程：粗筛（职位名 / 技能 / 工作词）→ 精排读 JD → 按数量和间隔投递。

自动排除：派遣/代招、校招、猎头、已投、不可选、职位名含实习/兼职。前程另排除网申（`applyType=1/2/3`）。看不出薪资或规模的岗位会留下。

### 2.0 其它

- 侧边栏随当前招聘站自动切 Tab；日志三端共用，切 Tab 不清空
- 今日已投只计成功数，按平台分记，每天归零
- 投递中可取消；间隔建议 3～5 秒
