# 招聘平台批量投递助手

Chrome 扩展，支持 BOSS 直聘、智联招聘三个平台的批量投递。

## 安装

1. 打开 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `extension/` 文件夹

## 使用

### BOSS 直聘

| 步骤      | 操作                                            |
| --------- | ----------------------------------------------- |
| 1. 搜职位 | 在 BOSS 搜索页输入关键词搜索                    |
| 2. 抓取   | 点扩展图标 → 🔵 BOSS Tab → **从搜索页抓取职位** |
| 3. 投递   | 设置数量、间隔 → **开始批量打招呼**             |

- 使用平台默认招呼语
- 自动调用搜索 API 获取 securityId，跳过详情页
- 触发风控自动停止并弹出 BOSS 页面

### 智联招聘

| 步骤      | 操作                                            |
| --------- | ----------------------------------------------- |
| 1. 搜职位 | 在智联搜索页输入关键词搜索                      |
| 2. 抓取   | 点扩展图标 → 🔴 智联 Tab → **从搜索页抓取职位** |
| 3. 投递   | 设置数量、间隔 → **开始批量投递**               |

- 自动识别附件简历并投递
- 使用平台默认招呼语
- 支持后台运行（关闭弹窗后继续）

## 功能

### 统计

- 每个 Tab 下方显示今日投递数
- 每天 0 点自动归零
- 超时和失败不计入统计

### 日志 & 会话

- 关闭弹窗后日志保留
- 切 Tab 显示对应平台日志
- 垃圾箱按钮清除日志
- 在对应平台页面打开扩展自动切 Tab

### 取消投递

- 投递过程中工具栏显示红色取消按钮
- 点击取消后剩余职位不再投递

### 诊断按钮

- 每个平台底部有诊断按钮
- BOSS：查看搜索 API 状态
- 智联：捕获投递 API 请求
- 前程无忧：捕获投递请求和卡片数据

## 文件结构

```
extension/
├── manifest.json      # 扩展配置
├── background.js      # 后台批处理服务
├── popup.html         # 弹出面板 UI
├── popup.js           # 面板逻辑（三平台）
├── content.js         # BOSS 页面桥接
├── inject.js          # BOSS API 调用
├── zcontent.js        # 智联页面桥接
├── zinject.js         # 智联 API 调用
```

## 注意事项

- Chrome 浏览器需保持打开
- 各平台需已登录且有默认简历
- 投递间隔建议 3~5 秒，过快可能触发风控
